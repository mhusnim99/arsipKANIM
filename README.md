# Arsip KANIM

Sistem Informasi Manajemen Arsip Kantor Imigrasi (KANIM).

## Fitur Utama
- Manajemen Lemari & Loker
- Penerimaan Arsip
- Penomoran Arsip Otomatis
- Pelacakan Lokasi Arsip
- Peminjaman & Pemusnahan Arsip

## Teknologi
- Laravel
- MySQL
- Bootstrap (SB Admin 2)
